# 세계수 봉헌의식

## 실행

macOS에서 이 폴더 안의 `실행.command`를 더블 클릭합니다. 터미널을 사용하는 경우 이 폴더에서 `python3 -m http.server 4173 --bind 127.0.0.1`을 실행한 뒤 [체험](http://127.0.0.1:4173/)을 엽니다. Python 3가 필요합니다. Three.js 및 체험 자료는 폴더에 포함되어 있습니다.

## 체험과 기록

인물과 장식을 고른 뒤 장식 집기, 제단에 놓기, 봉헌하기를 순서대로 진행합니다. 자동 여정은 약 2분이며 드래그나 방향키로 둘러볼 수 있습니다.

[봉헌 기록](http://127.0.0.1:4173/?page=archive)에서 완료한 인물의 생애, 봉헌일, 장식, 동작별 생애 기록을 다시 볼 수 있습니다. 저장은 현재 브라우저 프로필과 주소에 귀속됩니다. 같은 주소로 다시 접속해야 기존 기록이 나타납니다.

## 파일과 검증

- `src/life.js`에서 인물과 성장값을 생성합니다.
- `src/ornament.js`에서 여섯 SVG 요소의 부분 성장을 그립니다.
- `src/scene.js`에서 3D 이동과 공간을 구성합니다.
- `public/assets`에 웹용 GLB와 이미지가 있습니다. 상위 폴더의 원본 자료를 참조해 만들었습니다.
- Node.js가 있다면 `npm test`로 인생 생성, 반복 성장, 봉헌 상태 및 기록 계산을 검사할 수 있습니다.
