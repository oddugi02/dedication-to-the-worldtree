# 시작 화면 반응과 장식 3D 뷰어 설계

## 의도

첫 화면은 마우스에 반응하는 시네마틱한 깊이를 제공하되, 제목과 세계관 설명의 가독성을 유지합니다. 인물의 식물장식은 사용자가 제공한 여섯 개의 광택 GLB를 사용하며, 기존 성장 수치별 위치·반복 구성은 유지한 채 자유 회전이 가능해야 합니다.

## 결정

- 시작 화면에서만 포인터 위치를 `-1..1` 좌표로 변환해 CSS 변수로 제공합니다.
- 배경은 최대 18px, 빛 레이어는 최대 30px, 본문은 최대 6px 이동합니다. 제목은 최대 2.5% 확대와 0.8도 이내의 원근 기울기만 적용합니다.
- 화면을 벗어나면 값은 관성으로 중앙에 복귀합니다. 작은 화면·터치 입력·동작 줄이기 설정에서는 효과를 비활성화합니다.
- 장식 뷰어는 독립 Three.js 캔버스로 만들고, 기존 `ornament-placements.js`의 좌표와 성장 단계 반복 수를 그대로 사용합니다.
- 모델은 `감싸다·내밀다·버티다·받아들이다·뻗다·쌓다` 순서로 매핑합니다. 각 GLB는 복제하여 기존 단계별 반복 수를 재현합니다.
- 사용자는 드래그로 회전하고 휠·트랙패드로 확대/축소합니다. 뷰어 외 UI는 회전 동작에 영향을 받지 않습니다.
- 제공 GLB의 메시·재질·기본 구도는 변경하지 않습니다. 내장 텍스처만 최대 2048px로 줄여 배포용 복사본을 만듭니다.

## 범위 밖

- 봉헌 제단 위의 평면 장식 표현을 3D GLB로 교체하지 않습니다. 이 단계에서는 인물의 장식 감상 화면만 교체합니다.
- 성장 규칙, 인물 데이터, 장식 배치 수치 자체는 변경하지 않습니다.

## 검증

- 포인터 반응 계산은 단위 테스트로, 중앙 복귀와 최대 범위를 확인합니다.
- 기존 성장 구성 테스트는 유지하며, 뷰어가 기존 6개 축과 단계별 복제 수를 소비하는지 확인합니다.
- 브라우저에서 시작 화면과 장식 화면을 확인하고 콘솔 오류가 없는지 점검합니다.
